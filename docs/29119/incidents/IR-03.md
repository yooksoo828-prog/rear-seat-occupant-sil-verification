## 8.11.4 맥락

- TC-11 조건 11a-T50-nocomp / TC-04a, 요구 SR-09. 기준선 v1.0.
- 입력: 낮은 화물 R0(5 cm, 측정 대상 거리 95 cm), 온도 50 °C, 온도 보정 없음. 센서 모델은 c(T) = 331.4 + 0.6T를 쓰고, 판정기는 거리를 340 m/s 고정값으로 환산함.

## 8.11.5 사건 설명

- 기대: UNOCCUPIED. 실제: 300회 모두 OCCUPIED(오검출률 300/300, 목표 0.05).
- 같은 대상의 20 °C 보정 없음, 0 °C 보정 없음은 0/300. 50 °C 보정 있음(11b)도 0/300(tc11_side_by_side.csv).
- 계산: 50 °C에서 c = 361.4 m/s. 환산 거리 = 95 × 340 / 361.4 ≈ 89.375 cm, Δ = 100 − 89.375 = 10.625 cm ≥ Δ_on 10 cm.
- 별도 확인: results_p08r0의 잡음 없는 계산에서 Δ = 10.625 cm, 보정 있으면 5.0 cm로 기록됨(P-08-R0).
- **해석**: 고정 음속 환산이 고온에서 거리를 짧게 보이게 하여 낮은 화물이 임계값을 넘음. 위 계산과 P-08-R0이 일치하므로 원인 설명으로 삼았으나, 이 모델 자체가 문헌 식을 쓴 프로젝트 가정임.
