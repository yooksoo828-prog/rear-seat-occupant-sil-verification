# 기준선 v1.0 대 v1.1 본시험 결과 비교

> 이 문서는 `sil_main/compare_baselines.py`가 두 결과 폴더를 읽어 자동 생성한다. 직접 고치지 말고 스크립트로 다시 생성할 것.

## 1. 비교 대상

| 항목 | v1.0 | v1.1 |
| --- | --- | --- |
| 결과 폴더 | `results_main/` | `results_v1.1/` |
| 기준선 파일 | `baseline_v1.0.json` | `baseline_v1.1.json` |
| 기준선 SHA-256 | `79f21ce910853ee7…` | `9c1f4635563fc185…` |
| environment.temp_comp_base | False | True |
| 실행 명령 | `python3 run_main.py main` | `python3 run_main.py main baseline/baseline_v1.1.json results_v1.1` |

바꾼 것은 `environment.temp_comp_base`(온도 보정 기본값) 하나뿐이다. 입력, 난수 시드, 반복 횟수, 합격 기준은 같다.

## 5. 읽는 법

- 온도 보정을 기본값으로 켜도 **152개 결과 행의 판정은 하나도 바뀌지 않았는지**를 2절이 보여 준다.
- 4절은 보정이 실제로 적용되어 측정값이 달라졌는지를 보여 준다. 판정이 같아도 이 값이 달라야 보정이 적용된 것이다.
- 이 비교는 SIL 모델과 가상 반사면 입력에 대한 것이며 실제 센서의 성능을 뜻하지 않는다.
- v1.1은 추가 시험 케이스, 원 조건 대상 치수, H_s 110 cm 조건을 포함하지 않는다(`baseline_v1.1.json`의 `v1_1_scope` 참조).
