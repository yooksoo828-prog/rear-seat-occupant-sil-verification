## 8.9.3 시험 결과 — 판정 대응 규칙

29119-3 8.9.3은 시험 결과를 passed / failed / blocked로 기록하는 예를 들고 있음. summary.csv의 status 열과 아래처럼 대응시킴. **이 대응은 해석임**(표준이 이 프로젝트의 status 문구를 정한 것은 아님).

| 29119-3 용어 | summary.csv status 값 |
| --- | --- |
| passed | 목표 충족(통계 확인), 기준 충족(전 시행), 일치 |
| failed | 불합격 (사건 보고 번호를 함께 적음) |
| blocked | 미실행 (원인을 함께 적음) |
| (표준 분류 밖) 기록 | 기록(합격 판정 없음), 가정 기반 민감도 기록. 합격 기준이 없는 행이라 passed로 세지 않음 |

주의: 아래 숫자의 단위는 **summary.csv 행**임. 한 시험 조건이 미검출률·미확정률·기한 내 정답률처럼 지표별로 2~3행을 가져서 시험 케이스 수와 다름.
