## 8.5 추가: 대상 치수 조사 기록 (2026-11-13, 사용자 전달 문헌조사를 원문으로 대조)

이 절은 v1.1의 대상 반사면 높이 h_t 후보를 모은 것임. h_t는 방석 윗면에서 대상의 맨 윗점(정수리)까지의 수직 높이로 두고, 거리 d는 센서 높이 H_s에서 h_t를 뺀 값(d = H_s − h_t)으로 계산함(해석: 센서가 천장에서 아래를 보므로 가장 먼저 닿는 점을 정수리로 봄. 팀 확인 필요). 이는 센서 축과 대상이 수직으로 정렬된 이상적인 경우의 예상 거리이며, 머리 곡률·자세·축 어긋남 때문에 실제 측정 거리는 달라질 수 있음. 방석 눌림은 반영하지 않음(가정).

주의:

- Q 시리즈는 UN R129 충돌시험용 더미이며 Euro NCAP CPD 전용 더미가 아니라고 전달받은 문헌조사가 밝히고 있음. 따라서 O-S는 "6세 미만 소형 대상"의 기록용 대체값이고 CPD 대상 치수를 확인한 것이 아님.
- 사이즈코리아의 앉은키 측정 정의(어느 점부터 어느 점까지인지)는 이 세션에서 확인하지 못함. 위 값을 h_t로 쓰는 것은 해석임.
- 표의 수치 중 "직접 확인"은 사양표·논문 페이지에서 값을 읽었다는 뜻이며, 측정 방법·자세 조건까지 대조했다는 뜻이 아님.
- v1.1에서 값을 쓸 때는 상태 열을 그대로 가져가 결과 문서에 "문헌 기반", "추정", "대체"를 구분해 적음.

### 센서 높이 H_s 검토 (팀이 정할 것, 결정 아님)

- O-C 남성 95백분위는 H_s = 100 cm에서 d = 1.5 cm라 측정 가능 범위(2 cm) 밖임. 이 조건은 범위 밖 입력 처리(SR-11)에 걸릴 수 있음.
- 제안(AI): ① 기준선과의 비교를 위해 H_s = 100 cm 기본 구성은 바꾸지 않고, ② O-C 남성 95백분위는 "범위 밖 조건"으로 따로 기록하며, ③ 필요하면 H_s = 110 cm를 별도 조건으로 추가함(이 경우 d_empty도 110 cm가 되므로 기존 100 cm 결과와 합치지 않고 따로 기록). 변경하면 기준선 v1.1에 사유와 전후 값을 적어야 함.
- 이 제안은 근거 있는 규칙이 아니라 작성자의 제안임.

### 결정 기록 (2026-11-13)

- 센서 높이: H_s = 100 cm 기본 구성을 유지하고, H_s = 110 cm를 별도 조건으로 추가함. 팀 합의, 김*수가 대화에서 전달(합의 방법과 시각은 대화 기록 외에 확인되지 않음). 110 cm 조건은 d_empty도 110 cm가 되므로 100 cm 결과와 합치지 않고 따로 기록함. 110 cm 조건을 어느 대상에 적용할지는 구현할 때 정해 기록함(제안: O-C 조건. 아직 결정 아님).
- O-B: 추정 h_t = 63 cm(d = 37 cm)로 시험함. 팀 합의, 김*수 전달. 결과 문서에는 "추정 기반"으로 표시하고, 실측으로 확정된 원 조건으로 기록하지 않음. 대체 Q6(60.1 cm)는 원 조건과 구분해 별도 조건으로 둠. TM-01 엄격 커버리지에 O-B를 산입할지는 정하지 않았고, 집계 때 "추정 기반"을 별도 표시해 두 가지 수치를 병기함(제안).
- 위 외 치수(O-A 63.5 cm, O-C 전체 50백분위 90.3 cm, O-S는 기록용)는 이 절 표의 값을 사용함.
- 이 결정이 v1.0 결과에 영향을 주지 않으며, 기준선 v1.1에 변경 항목별 사유와 전후 값을 적음(TP-01 7.2.7.7·7.2.7.13).
