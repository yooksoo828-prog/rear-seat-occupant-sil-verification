## 공통 규칙 (계획서 7.2.7.5 발췌)

- 커버리지 C = N ÷ T × 100%.
- 대체 조건(R1·R2·R3)은 원 조건(O-A·O-B·O-C)의 N에 산입하지 않는 엄격 수치를 기본으로 보고하고, 산입 수치를 별도 표시함.
- 수행 불가 항목은 T에서 빼지 않고, 빼고 계산한 수치를 별도 표시함.
- 경계값 분석은 3-value(경계 바로 아래, 경계, 경계 바로 위)로 하고 증분은 판정값 1 cm로 통일함(이 계획서의 선택, 시험 설계 문서에 증분 규칙은 없음). 증분 1 cm가 아닌 역사적 실행 값(Δ = 6·9 cm)은 기록은 하되 커버리지 항목으로 세지 않음.
- 현재 수치는 **v1.0 결과 파일(summary.csv)에서 직접 세었음**.
- **커버리지 항목 우선순위 규칙 (29119-3 8.3.2.4, 2026-11-17 추가, 제안)**: 원본에는 모델 단위 우선순위만 있었다. 커버리지 항목의 우선순위는 **소속 모델의 우선순위를 그대로 따른다**(TM-01~TM-04의 항목은 높음, TM-05의 항목은 중간). 항목별로 달리 정하는 것은 팀이 확정할 때 한다.
