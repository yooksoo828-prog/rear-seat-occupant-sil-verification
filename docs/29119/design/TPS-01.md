## 8.4.5 시작 (start up)

1. 폴더: sil_main/ 옆에 sil_prelim/이 있어야 함. run_main.py가 ../sil_prelim/run_prelim.py를 불러옴. (2026-11-12 재현 중 이 의존을 처음 확인함. 없으면 FileNotFoundError.)
2. Python 3.10 이상, numpy(README). v1.0 실행 기록: Python 3.13.18, numpy 2.5.3(results_main/config.json).
3. baseline/baseline_v1.0.json이 있고 confirmed = true, sha256 79f21ce910853ee7358d97c031a7553258a9fb2151bdcdaca17db3c1ea205f6d.
4. (권장) python3 selftest.py: 통계 수치, 예비시험 재현, 사전점검·본시험 두 번 실행 동일, 집계 재계산 점검(selftest.py 설명과 README).
5. **결과 보관**: python3 run_main.py main은 results_main/을 지우고 다시 만듦(README). 다시 실행하기 전에 이전 결과를 복사해 두어야 함.
