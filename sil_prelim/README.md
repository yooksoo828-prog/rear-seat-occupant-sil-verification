# 뒷좌석 승객 감지 SIL — 예비시험 (P-01~P-08)

5단계 문서 「요구사항·시험 설계」 v0.4.1의 10절(예비시험)을 구현한 코드임.
예비시험은 SIL 구현과 시험 환경의 문제를 찾는 단계이며, 결과를 본시험의 통계적 성능 입증으로 쓰지 않음.
대상은 가정 반사면 R0~R3이며 6세 더미나 인체를 대표하지 않음.

## 실행

```
python3 run_prelim.py results     # 예비시험 실행, results/ 에 로그 저장 (1초 이내)
python3 make_report.py results    # results/report.md 생성
```

필요: Python 3.10 이상, numpy. 같은 명령을 다시 실행하면 모든 출력 파일이 바이트 단위로 같게 나옴(시드 고정).

## 구성 (역할별 분리)

| 파일 | 역할 |
|---|---|
| `sil/config.py` | 예비시험 설정값과 구분([문헌]/[계산값]/[구현 설정(예비)]/[프로젝트 가정]) |
| `sil/scenario.py` | 입력 생성(대상·반사면·움직임·고장 주입)과 정답. 정답은 시나리오 정의로만 정함 |
| `sil/sensor_model.py` | HC-SR04 모델(물리 측). 온도별 음속, 잡음, 반사 손실, 타임아웃 → 에코 펄스 폭 |
| `sil/detector.py` | 점유 판단 소프트웨어(검증 대상). 거리 환산, 중앙값 필터, 히스테리시스, INIT·UNKNOWN·복구, 갱신 중단 감시 |
| `sil/simulate.py` | 시행 1회 실행(센서 모델 → 판단 소프트웨어), 로그 수집 |
| `sil/evaluate.py` | 판정 시점 출력, 최초 판정 시각, 응답 시간(9.3절), 뒤집힘, 측정 주기, 비율 |
| `run_prelim.py` | P-01~P-08 시험 정의와 실행. 결정적 시험(P-03→P-04→P-05→P-06) 먼저, 이후 무작위·민감도 |
| `make_report.py` | 시험별 기대·실제·일치·원인 표 생성 |

## 출력 (results/)

| 파일 | 내용 |
|---|---|
| `config.json` | 모든 설정값, Python·numpy 버전, 난수 생성기, 시드 규칙 |
| `results.csv`, `report.md` | 시험 항목별 기대 결과, 실제 결과, 일치 여부, 원인 구분 |
| `trial_samples.csv` | 시행별 모든 측정 요청: 요청·수신 시각, 상태(echo/timeout/stalled), 원인, 참 거리, 잡음, 펄스 폭, 환산 거리, 중앙값, Δ, 출력, 정답, 시드 |
| `output_log.csv` | 시행별 출력 변화 시각 |
| `events.csv` | UNKNOWN 진입, 복구 첫 유효 샘플, 유효 판정 등 사건 |
| `p08_sensitivity.csv` | P-08 조건별 결과 |

## 원인 구분

- 구현 오류: 코드가 문서 규칙과 다르게 동작한 경우
- 문서 모호함: 코드는 문서대로 동작했으나 문서 정의가 결과를 하나로 정하지 못한 경우
- 알고리즘 특성: 문서 규칙대로 동작한 결과가 요구와 다른 경우(예: 같은 거리 입력은 구분 불가)
- 모델 가정 민감도: 근거 없는 가정값(잡음, 손실 등)을 바꿨을 때 나타난 결과
