1. **가상 반사면 대체 (D1)**: O-A/O-B/O-C의 반사면 높이 근거가 없어(시험 설계 4.3·12절 TBR) 프로젝트 가정 반사면 `R0~R3 = 5/20/40/60 cm`로 대체함. TC-02a=R1, TC-02b=R2, TC-03=R3 는 **'가상 반사면 대체 조건'**이며 실제 더미·인체·가방의 치수가 아니고 O-A/O-B/O-C 원 조건의 결과가 아님(결과 표 `surface` 열에 표시).
2. **미실행**: O-A·O-B·O-C 원 조건, **TC-12(O-S)** 는 입력(치수) 부재로 실행하지 않음(4.2절).
3. **단일점 높이 센서 한계**: 센서 바로 아래 **한 점의 높이만** 모델링함. 착석 위치 분포(off-axis)는 모델에 없음(기준선 `seating_position_distribution`: "없음: 센서 바로 아래 한 점의 높이만 모델링함(착석 위치 분포는 SIL 모델에 없음, 후속 검토)"). 같은 거리 이력을 갖는 화물과 사람은 거리 입력만으로 구분할 수 없음(INC-01·INC-02).
4. **d_empty 고정 (D4)**: 100 cm 고정이며 초기 빈 좌석 실측 보정은 모델에 없음.
5. **전원·시동 (D8)**: TC-08은 t = 0 전원 인가 SIL 모델이며 차량 시동과 센서 전원의 관계는 모델에 없음.

### 1.4 Pass/Fail Criteria (통계적 합격·불합격 기준)

| 지표 | 목표(D6) |
|---|---|
| 미검출률 (miss rate) | ≤ 1% |
| 오검출률 (false alarm rate) | ≤ 5% |
| 미확정률 (UNKNOWN rate) | ≤ 1% |
| 응답 시간 | ≤ 3 s 및 정답 유지 |
| 출력 뒤집힘(flip) | 0회 |

**판정 방법**: 오류율은 독립 시행 수 기준이며 UNKNOWN은 분모에 포함하고 미확정률로 따로 계산함. 신뢰수준 95 %의 **단측 정확 이항 상한(Clopper-Pearson)** p_U 는 `P(X ≤ k | n, p_U) = 0.05` 의 해이며, k = 0 이면 `(1 − p_U)^n = 0.05` 임(시험 설계 9.4절, D5/D6).

```
관측 비율 k/n > 목표                → 불합격
관측 비율 ≤ 목표 이고 상한95 ≤ 목표  → 목표 충족(통계 확인)
관측 비율 ≤ 목표 이고 상한95 > 목표  → 관측 충족(통계 미확인)
```

오류 0건으로 상한 95 %가 목표 이하가 되는 최소 시행 수: 목표 1 % → **299회**, 목표 5 % → **59회**.

**상한 95 % 계산표 (이 스크립트가 독립 계산)**

| 오류 k | n = 300 상한95 | n = 60 상한95 |
|---|---|---|
| 0 | 0.994% | 4.87% |
| 1 | 1.571% | 7.664% |
| 2 | 2.084% | 10.124% |
| 3 | 2.564% | 12.419% |
| 4 | 3.025% | 14.61% |

**n = 60 일 때 판정이 갈리는 조건 (`관측 충족(통계 미확인)`의 조건부 인정 기준)**

| 목표 | n | k 에 따른 판정 |
|---|---|---|
| 오검출률(목표 5 %) | 60 | 목표 충족(통계 확인): k = 0; 관측 충족(통계 미확인): k = 1~3; 불합격: k ≥ 4 |
| 오검출률(목표 5 %) | 300 | 목표 충족(통계 확인): k = 0~8; 관측 충족(통계 미확인): k = 9~15; 불합격: k ≥ 16 |
| 미검출률·미확정률(목표 1 %) | 60 | 관측 충족(통계 미확인): k = 0; 불합격: k ≥ 1 |
| 미검출률·미확정률(목표 1 %) | 300 | 목표 충족(통계 확인): k = 0; 관측 충족(통계 미확인): k = 1~3; 불합격: k ≥ 4 |

> `n = 60` 에서 오검출 목표 5 %는 k = 0 이면 상한 95 %가 4.87 % 로 목표 이하라 *통계 확인*, k = 1~3 이면 관측 비율은 목표 이하이나 상한이 목표를 넘어 *관측 충족(통계 미확인)*, k ≥ 4 이면 *불합격*임. 목표 1 %는 n = 60 에서 k = 0 이어도 상한이 4.87 % 라 *통계 미확인*에 그침(최소 299회 필요). **이 보고서의 152개 결과 중 `관측 충족(통계 미확인)` 행은 0개**임.

### 2.2 Deterministic Seed Rule (결정적 시드 규칙)

```
seed = base_seed * 2**64 + crc32('<접두>/<TC>/<조건>') * 2**20 + 시행 번호
base_seed = 20261111   (본시험 접두 없음, 사전점검 접두 'PRE/')
```

- 조건마다 독립이며 시행 수 제한은 2**20 임(예비시험 규칙은 시행 100회 이상에서 이웃 조건과 겹칠 수 있어 바꿈).
- 난수 생성기: numpy.random.PCG64 via SeedSequence(seed).spawn. 잡음·손실 난수는 서로 독립임.
- 재계산 예: `TC-13/13a-drop4-det` 시행 1 → crc32 = 354728545, seed = 373751529266393366890807297 (`trials.csv` 기록과 일치). 전 시행 재계산 결과는 3.1절.
